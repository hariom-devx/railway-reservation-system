## Detailed Version (for project section)

### Railway Reservation System
*Technologies: C (C11), GCC, Make, Binary File I/O, Data Structures*

- Designed and implemented a **console-based railway reservation system** managing tickets, passengers, trains, and waiting lists  
- Used **Binary Search Tree** for O(log n) train search keyed by train number; **Linked List** for dynamic passenger records  
- Applied **Queue (FIFO)** for fair waiting list seat allocation and **Stack (LIFO)** for undo-cancellation feature  
- Integrated **binary file persistence** (`fread`/`fwrite`) for trains, bookings, passengers, queue, and stack across sessions  
- Delivered admin module for train CRUD, fare updates, and revenue statistics; modular architecture with 9 header files and Makefile build
